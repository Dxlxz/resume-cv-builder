# Development Run Records

**Reader:** contributors and reviewers · **Answers:** how is an AI-authored change attributed?

Follow the [CLEAR lite contract](../../../AGENTS.md#5-delivery--clear-lite).

One Markdown record per **L2+ change that has no feature packet**, named `<YYYY-MM-DD>-<topic>.md`. L0/L1 changes
are recorded by their commit message, not here. Delete records nothing current links to; git keeps them.

A record states: who authorized it (with the instruction quoted), the agent and model, the branch, the class, what
changed, the evidence (command and result line per check), the independent review verdict, and what was not done.
No private chain-of-thought.
